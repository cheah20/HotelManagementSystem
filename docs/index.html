Hotel Management System

A desktop app for hotel front desk staff, built with Java Swing and MariaDB for my Year 2 Object Oriented Programming course at UTeM.

Staff log in, register customers and rooms, take bookings with meals and member discounts, then bill and collect payment. Every window below is a real screenshot from Windows, using the made-up sample data.
